# Portfolio GitHub Pages

Folder ini berisi website portofolio sederhana yang siap di-upload ke GitHub Pages.

## Struktur
- index.html  -> halaman utama
- style.css   -> tampilan website
- script.js   -> JavaScript
- assets/     -> tempat foto/logo jika ingin ditambahkan

## Cara upload ke GitHub Pages

1. Login ke GitHub.
2. Buka profil GitHub kamu.
3. Klik tombol `New` untuk membuat repository baru.
4. Nama repository HARUS:
   `eliaandrito-xyz.github.io`
5. Pilih `Public`.
6. Klik `Create repository`.
7. Di repository, klik `Add file` -> `Upload files`.
8. Buka folder hasil ZIP ini, lalu upload:
   - index.html
   - style.css
   - script.js
   - folder assets (jika ada)
9. Klik `Commit changes`.
10. Buka `Settings` -> `Pages`.
11. Pada `Build and deployment`, pilih:
    - Source: `Deploy from a branch`
    - Branch: `main`
    - Folder: `/ (root)`
12. Klik `Save`.
13. Tunggu beberapa saat.
14. Website akan tersedia di:
    `https://eliaandrito-xyz.github.io`

## Sebelum online
Ganti data berikut di index.html:
- Email
- LinkedIn
- Nama jika ingin menggunakan nama lengkap
- Deskripsi proyek jika diperlukan

Jangan pernah memasukkan password, token, API key, atau data rahasia ke dalam repository.

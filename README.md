## 🚀 Cara Mempublikasikan ke GitHub Pages

1. Login ke akun [GitHub](https://github.com).
2. Buat repositori baru bernama: `eliaandrito-xyz.github.io`
3. Push/Upload seluruh berkas repositori ini (termasuk folder `assets/`).
4. Buka **Settings** -> **Pages** pada repositori GitHub.
5. Pada bagian **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`
6. Simpan (*Save*). Dalam 1-2 menit, website portofolio akan aktif di:
   👉 **https://eliaandrito-xyz.github.io**
